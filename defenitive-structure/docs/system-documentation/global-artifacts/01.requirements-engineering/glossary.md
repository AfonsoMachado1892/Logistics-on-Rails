# Glossary

**Terms, Expressions, and Acronyms (TEA) must be organized alphabetically.**

| **_TEA_** (EN)                        | **_Description_** (EN)                                                                                                                                                                                           |
|:--------------------------------------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **2D-TREE (KD-TREE)**                 | A system for indexing railway stations by location, enabling fast geographic queries (like 'nearest stations' or 'stations in an area').                                                                         |
| **AISLE**                             | Path between warehouse bays allowing access for picking/storage operations.                                                                                                                                      |
| **ALLOCATION ROW**                    | Record representing the specific quantity of a product (SKU) allocated from a box in a bay to fulfill part of an order line.                                                                                     |
| **BAY**                               | A limited storage space within a warehouse aisle for boxes.                                                                                                                                                      |
| **BEST FIT DECREASING (BFD)**         | A packing heuristic where items are sorted by weight (largest to smallest) and then placed into the batch (trolley) with the tightest fit (smallest remaining capacity).                                         |
| **BOGIE**                             | Wheel assemblies that support a wagon or locomotive. The number and type influence stability and speed.                                                                                                          |
| **BOX**                               | The basic storage unit for a product (SKU), identified by a `boxId` and having a quantity, optional expiry date, and received-at timestamp.                                                                      |
| **BOXCAR**                            | Freight wagon designed to transport general goods that require protection from weather conditions.                                                                                                               |
| **BRIDGE**                            | Engineering structure that supports railway lines over obstacles.                                                                                                                                                |
| **BUILDING**                          | A structure located within a facility, classified by a building type.                                                                                                                                            |
| **CARGO HANDLING**                    | Process of unloading, storing, and dispatching goods at a railway terminal.                                                                                                                                      |
| **CIRCULATION LINES**                 | Tracks within a railway terminal where wagons circulate to reach parking areas or unloading docks.                                                                                                               |
| **COMPLEX ROUTE**                     | A route that includes multiple freights.                                                                                                                                                                         |
| **CROSSING (TRAIN)**                  | The operation where trains pass each other, which must be planned at sidings or stations when on single-track lines.                                                                                             |
| **CYCLE COUNT**                       | An inventory audit. In the context of returns, it's a reason for quarantine to recheck a mismatch found during an audit.                                                                                         |
| **DIMENSIONS**                        | Physical measurements (length, width, height) of rolling stock.                                                                                                                                                  |
| **FACILITY**                          | Any physical node in the railway network, such as a freight yard, station, or terminal.                                                                                                                          |
| **FEFO**                              | “First Expired, First Out” – An inventory principle for perishable goods, ensuring items closest to their expiry date are dispatched first.                                                                      |
| **FIFO**                              | “First In, First Out” – An inventory principle for non-perishable goods, ensuring items that arrived earliest (oldest `receivedAt` date) are dispatched first.                                                   |
| **FIRST FIT (FF)**                    | A packing heuristic where an item is placed into the first batch (trolley) where it fits, scanned in input order.                                                                                                |
| **FIRST FIT DECREASING (FFD)**        | A packing heuristic where items are sorted by weight (largest to smallest) and then placed into the first batch (trolley) where they fit.                                                                        |
| **FREIGHT**                           | A set of wagons that must be transported from an origin endpoint to a destination endpoint.                                                                                                                      |
| **FREIGHT MANAGER**                   | A system user responsible for analyzing, designing, and adjusting train timetables and dispatching trains.                                                                                                       |
| **FUEL CAPACITY**                     | The amount of fuel a diesel engine locomotive can hold.                                                                                                                                                          |
| **GAUGE**                             | Distance between the inner sides of the two rails of a track.                                                                                                                                                    |
| **GEOGRAPHICAL AREA (RANGE)**         | A rectangular map region defined by minimum/maximum latitude and longitude, used for querying stations in the 2D-Tree.                                                                                           |
| **GRAIN SILO**                        | A specialized building type within a facility used for the bulk storage of grain.                                                                                                                                |
| **INTERMODAL TERMINAL**               | A facility allowing transfer of goods (containers) between different transport modes (e.g., train, truck, ship).                                                                                                 |
| **INVENTORY**                         | Collection of all boxes (SKUs) stored and managed in the warehouse.                                                                                                                                              |
| **LINE SEGMENT**                      | A portion of a railway line, composing part of the connection between two endpoints.                                                                                                                             |
| **LOCOMOTIVE**                        | Engine-powered vehicle that pulls freight wagons.                                                                                                                                                                |
| **LOCOMOTIVE TYPE**                   | Classification defining the power source: Diesel or Electric.                                                                                                                                                    |
| **LOGISTICS**                         | The management, planning, and execution of transporting freight by train, from origin to destination.                                                                                                            |
| **MAKER**                             | Manufacturer of a piece of rolling stock (e.g., wagon model).                                                                                                                                                    |
| **MAX SPEED**                         | Numeric value representing the maximum operational speed of the rolling stock.                                                                                                                                   |
| **ORDER**                             | A customer request for products, identified by `orderId` and having a `dueDate` and `priority`.                                                                                                                  |
| **ORDER LINE**                        | An individual item and quantity requested within a customer order.                                                                                                                                               |
| **OWNER**                             | An entity responsible for a railway line and its maintenance.                                                                                                                                                    |
| **PARKING LINES**                     | Sidings within a terminal where wagons wait temporarily.                                                                                                                                                         |
| **PAYLOAD**                           | Maximum weight or volume of goods that a wagon can carry.                                                                                                                                                        |
| **PICKER**                            | A warehouse worker responsible for collecting products (boxes) from bays to fulfill picking plans.                                                                                                               |
| **PICKING PLAN**                      | A list of allocations (order, SKU, bay, etc.) grouped into a capacity-bounded trolley.                                                                                                                           |
| **POWER**                             | The energy output of a locomotive, a key factor in calculating travel speed.                                                                                                                                     |
| **PRODUCT OWNER**                     | Person responsible for defining user stories and ensuring project alignment with goals.                                                                                                                          |
| **PROXIMITY SEARCH (NEAREST-N)**      | A query to find the 'N' nearest stations to a given (latitude, longitude) coordinate.                                                                                                                            |
| **QUALITY OPERATOR**                  | A user responsible for managing returned goods, inspecting items in quarantine, and deciding whether to restock or discard them.                                                                                 |
| **QUARANTINE**                        | A temporary holding state for returned products. Items are inspected in LIFO order (latest first) before being restocked or discarded.                                                                           |
| **RADIUS SEARCH**                     | A query to find all stations within a specific radius (in km) of a target (latitude, longitude) coordinate.                                                                                                      |
| **RAILWAY INFRASTRUCTURE**            | Physical components of the railway network: tracks, stations, terminals, etc..                                                                                                                                   |
| **RAILWAY LINE**                      | A set of connected track segments forming a route between two endpoints.                                                                                                                                         |
| **RAILWAY TERMINAL**                  | A complex logistics node where freight wagons arrive to be unloaded, stored in warehouses, and dispatched.                                                                                                       |
| **REFRIGERATED CAR**                  | Freight wagon with cooling systems to transport perishable goods.                                                                                                                                                |
| **RETURN**                            | A product sent back to the warehouse, which must be placed in quarantine for inspection.                                                                                                                         |
| **ROLLING STOCK**                     | All vehicles operating on railways, including locomotives and wagons.                                                                                                                                            |
| **ROUTE**                             | The ordered list of stations through which a train must pass to travel from an origin to a destination.                                                                                                          |
| **SCHEDULER**                         | A system used by the Freight Manager to dispatch trains, calculate estimated passage times, and plan necessary train crossings.                                                                                  |
| **SERVICE YEAR**                      | The year a piece of rolling stock (locomotive or wagon) entered into service.                                                                                                                                    |
| **SIDING**                            | Secondary track allowing trains to pass or park on single-track lines.                                                                                                                                           |
| **SIMPLE ROUTE**                      | A route that consists of a single freight.                                                                                                                                                                       |
| **SKU**                               | Stock Keeping Unit – A unique identifier for a product in inventory.                                                                                                                                             |
| **STATION**                           | A node of the railway network for loading/unloading, train crossing, or assembly.                                                                                                                                |
| **STATION MASTER**                    | User for coordinating station operations, including arrivals and departures.                                                                                                                                     |
| **STATION STORAGE MANAGER**           | User responsible for managing warehouse storage and cargo at a station. (Also: Terminal Operator, Warehouse Manager).                                                                                            |
| **STOCK**                             | The total amount of goods (boxes) stored in the warehouse.                                                                                                                                                       |
| **TANK CAR**                          | Freight wagon designed to carry liquids or gases, such as fuel or chemicals.                                                                                                                                     |
| **TIME ZONE GROUP**                   | A classification for railway stations based on their time zone (e.g., 'CET', 'WET/GMT'), used for indexing.                                                                                                      |
| **TRACK (RAIL)**                      | Physical path composed of rails and sleepers where trains run.                                                                                                                                                   |
| **TRACK LIGHTS (COMMANDS)**           | A set of commands/states for track signaling: **GE** (Green, track free), **RE** (Red, track busy), **YE** (Yellow, free but assigned), **RB** (Red-blinking, track inoperative), **GTH** (Go To Home/Synoptic). |
| **TRAIN DISPATCHER**                  | Operator responsible for scheduling and managing train movements. (Also: Traffic Dispatcher).                                                                                                                    |
| **TRAIN DRIVER**                      | Professional responsible for operating trains, following schedules, and ensuring safe movement. (Also: Locomotive Pilot).                                                                                        |
| **TROLLEY**                           | Wheeled cart with a fixed weight capacity, used by warehouse pickers to collect and transport boxes during the picking process.                                                                                  |
| **UNLOADING DOCKS**                   | Access points to warehouses, where goods are unloaded from wagons for storage.                                                                                                                                   |
| **WAGON / FREIGHT CAR**               | Railway vehicle designed to transport goods.                                                                                                                                                                     |
| **WAGON MODEL**                       | A specific design or version of a freight wagon, defining its characteristics (payload, type, etc.).                                                                                                             |
| **WAREHOUSE (BUILDING)**              | A building type within a facility used for the general storage of goods.                                                                                                                                         |
| **WAREHOUSE MANAGEMENT SYSTEM (WMS)** | The software system (ESINF component) controlling inventory and cargo handling operations.                                                                                                                       |
| **YARD**                              | Area where trains are assembled, loaded, or unloaded.                                                                                                                                                            |
| \**...**                              | ...                                                                                                                                                                                                              |
