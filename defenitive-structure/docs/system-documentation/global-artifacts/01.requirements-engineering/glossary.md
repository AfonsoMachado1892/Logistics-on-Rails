# Glossary

**Terms, Expressions and Acronyms (TEA) must be organized alphabetically.**

| **_TEA_** (EN)                                                  | **_Description_** (EN)                                                                                                                                                   |
|:----------------------------------------------------------------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **AISLE**                                                       | Path between warehouse bays allowing access for picking/storage operations.                                                                                              |
| **ALLOCATION ROW**                                              | Record representing the specific quantity of a product (SKU) allocated from a box in a bay to fulfill part of an order line.                                             |
| **BAY**                                                         | A limited storage space within a warehouse aisle for boxes.                                                                                                              |
| **BEST FIT DECREASING (BFD)**                                   | A packing heuristic where items are sorted by weight (largest to smallest) and then placed into the batch (trolley) with the tightest fit (smallest remaining capacity). |
| **BOOGIE**                                                      | Wheel assemblies that support a wagon or locomotive. The number and type influence stability and speed.                                                                  |
| **BOX**                                                         | The basic storage unit for a product                                                                                                                                     |
| **BOXCAR**                                                      | Freight wagon designed to transport general goods that require protection from weather conditions.                                                                       |
| **BRIDGE**                                                      | Engineering structure that supports railway lines over obstacles.                                                                                                        |
| **BUILDING**                                                    | A structure located within a facility, classified by a building type.                                                                                                    |
| **CARGO HANDLING**                                              | Process of unloading, storing, and dispatching goods.                                                                                                                    |
| **CIRCULATION LINES**                                           | Tracks where wagons circulate to reach the parking areas or unloading docks                                                                                              |
| **CYCLE COUNT**                                                 | Inventory audit used to detect mismatches between physical and recorded stock.                                                                                           |
| **DIMENSIONS**                                                  | Physical measurements (length, width, height) of rolling stock                                                                                                           |
| **FACILITY**                                                    | Any physical or functional unit within the railway logistics system, such as terminals, warehouses, or stations                                                          |
| **FEFO**                                                        | “First Expired, First Out” – inventory rule for perishable goods.                                                                                                        |
| **FIFO**                                                        | “First In, First Out” – inventory rule for non-perishable goods (older products before newer ones.                                                                       |
| **FIRST FIT (FF)**                                              | A packing heuristic where an item is placed into the first batch (trolley) where it fits, scanned in input order.                                                        |
| **FIRST FIT DECREASING (FFD)**                                  | A packing heuristic where items are sorted by weight (largest to smallest) and then placed into the first batch (trolley) where they fit.                                |
| **FREIGHT**                                                     | Set of wagons transporting goods from one station to another.                                                                                                            |
| **FREIGHT MANAGER**                                             | User in charge of coordinating cargo allocation and logistics management.                                                                                                |
| **FUEL CAPACITY**                                               | The amount of fuel a diesel engine locomotive can hold.                                                                                                                  |
| **GAUGE**                                                       | Distance between the inner sides of the two rails of a track.                                                                                                            |
| **INTERMODAL TERMINAL**                                         | Facility allowing transfer of goods between transport modes (train, truck, ship).                                                                                        |
| **INVENTORY**                                                   | Collection of goods stored and managed in warehouses or terminals.                                                                                                       |
| **LINE SEGMENT**                                                | Portion of a railway line between two consecutive stations or junctions.                                                                                                 |
| **LOCOMOTIVE**                                                  | Engine-powered vehicle that pulls freight wagons.                                                                                                                        |
| **LOCOMOTIVE TYPE**                                             | Classification defining the power source: Diesel or Electric.                                                                                                            |
| **LOGISTICS**                                                   | Management and coordination of the flow of goods, information, and resources.                                                                                            |
| **MAKER**                                                       | Manufacturer of a piece of rolling stock.                                                                                                                                |
| **MAX SPEED**                                                   | Numeric value representing the maximum operational speed of the rolling stock.                                                                                           |
| **ORDER**                                                       | A customer request for products to be dispatched, containing one or more order lines with specified SKUs and quantities.                                                 |
| **ORDER LINE**                                                  | Individual item record within a customer order.                                                                                                                          |
| **OWNER**                                                       | An entity responsible for a railway line.                                                                                                                                |
| **PARKING LINES**                                               | Sidings where wagons wait temporarily before being sent to another destination                                                                                           |
| **PAYLOAD**                                                     | Maximum weight or volume of goods that a wagon can carry.                                                                                                                |
| **PICKING PLAN**                                                | Optimized plan to collect goods from warehouse bays.                                                                                                                     |
| **POWER**                                                       | The energy a locomotive uses                                                                                                                                             |
| **RAILWAY INFRASTRUCTURE**                                      | Physical components of the railway network: tracks, stations, terminals, etc.                                                                                            |
| **RAILWAY LINE**                                                | Set of connected track segments forming a route between stations.                                                                                                        |
| **RAILWAY TERMINAL**                                            | Facility where wagons are received, unloaded, and dispatched.                                                                                                            |
| **REFRIGERATED CAR**                                            | Freight wagon with cooling systems to transport perishable goods that require temperature control.                                                                       |
| **RETURN (QUARANTINE)**                                         | Temporary hold of returned products until inspection before being discarded or restocked.                                                                                |
| **ROUTE**                                                       | Path a train takes between two or more stations.                                                                                                                         |
| **ROLLING STOCK**                                               | All vehicles operating on railways, including locomotives and wagons.                                                                                                    |
| **SCHEDULER / PLANNER**                                         | User responsible for creating and adjusting train timetables to improve efficiency.                                                                                      |
| **SERVICE YEAR**                                                | The year a piece of rolling stock entered into service.                                                                                                                  |
| **SIDING**                                                      | Secondary track allowing trains to pass or park on single-track lines.                                                                                                   |
| **SKU**                                                         | Stock Keeping Unit – unique identifier for a product in inventory.                                                                                                       |
| **STATION**                                                     | Node of the railway network for loading/unloading or train crossing.                                                                                                     |
| **STATION MASTER**                                              | User for coordinating station operations and arrivals and departures.                                                                                                    |
| **STATION STORAGE MANAGER/TERMINAL OPERATOR/WAREHOUSE MANAGER** | User responsible for managing warehouse storage and cargo at a station.                                                                                                  |
| **STOCK**                                                       | The total amount of goods stored in the warehouse.                                                                                                                       |
| **TANK CAR**                                                    | Freight wagon designed to carry liquids or gases, such as fuel or chemicals.                                                                                             |
| **TRACK (RAIL)**                                                | Physical path composed of rails and sleepers where trains run.                                                                                                           |
| **TRAIN DISPATCHER**                                            | Operator responsible for scheduling and managing train movements.                                                                                                        |
| **TRAIN DRIVER / LOCOMOTIVE PILOT**                             | Professional responsible for operating trains, following schedules, and ensuring safe movement.                                                                          |
| **TROLLEY**                                                     | Wheeled cart used by warehouse pickers to collect and transport boxes during the picking process.                                                                        |
| **UNLOADING DOCKS**                                             | Access points to warehouses, where goods are unloaded for longer storage.                                                                                                |
| **WAGON / FREIGHT CAR**                                         | Railway vehicle designed to transport goods.                                                                                                                             |
| **WAGON MODEL**                                                 | A specific design or version of a freight wagon, defining its characteristics.                                                                                           |
| **WAREHOUSE MANAGEMENT SYSTEM (WMS)**                           | Software system controlling inventory and cargo handling operations.                                                                                                     |
| **YARD**                                                        | Area where trains are assembled, loaded, or unloaded.                                                                                                                    |
| **...**                                                         | ...                                                                                                                                                                      |                             |
